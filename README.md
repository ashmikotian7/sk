# SK's Digital Soirée

Create a unique, elegant, cinematic 3D birthday wishing website for my best friend SK.

The website should feel like a luxury digital birthday experience, not a normal birthday template. It should be emotional, sophisticated, minimal, immersive, and visually memorable.

CORE THEME

Birthday girl: SK

Color palette:

- Deep Black: #080808
- Soft White / Ivory: #F5F1EA
- Deep Wine / Burgundy: #6B1E35
- Dark Wine: #3A0D1C
- Very subtle metallic/soft highlights

Do NOT use bright pink, childish birthday colors, rainbow colors, balloons everywhere, cartoon elements, or generic birthday templates.

The overall visual language should be:
Luxury + Cinematic + 3D + Elegant + Emotional + Mysterious + Personal

Use generous negative space, beautiful typography, subtle animations, depth, reflections, shadows, and smooth transitions.

---

TECHNOLOGY

Build it as a modern responsive web application using:

- React / Next.js
- TypeScript
- Tailwind CSS
- Three.js
- React Three Fiber
- @react-three/drei
- GSAP or Framer Motion
- Lucide icons

Use 3D elements carefully so the website remains elegant and performant.

The website must work beautifully on:

- Desktop
- Laptop
- Tablet
- Mobile
